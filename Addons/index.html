Addons are additional optional content that you can download for more extra features. Usually game features that are not that popular or do not require to be implemented in the core package, are separated into addons. Addons are just normal plugins, but are linked to the plugin in a special way which allows them to be enabled/disabled/reloaded properly unlike PlugMan plugins and other things.

Addons might introduce new game modes, or add compatibility for other plugins.

If you're running a server and you want to download addons, you can view everything from /k admin addons GUI.

Available Addons:
* Outposts
* Map Viewers: Adds support for kingdom icons and makers.
* Peace Treaties
* EngineHub
* Admin Tools
* UltimaAddons: An unofficial addon from discord user leomelonseeds(327608730831028224) which contains a variety of other features. This addon is not intended to be for public use, so you might want to recompile the addon yourself with necessary changes. One of the purposes of this addon was to implement a suggested feature regarding outpost disconnected lands faster.

Related FAQ: Network issues with addons

If you're a developer, and you want to make an addon for kingdoms, visit the Addons API section

Note that you shouldn't be looking to make an addon if you simply just want to add compatibility for kingdoms to your plugin. In that case just refer the the API page in general.
