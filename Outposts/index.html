This addon adds a game mode to the plugin which is similar to King of The Hill (KoTH) styled gameplay.

Note

This outpost does not refer to the Outpost structure. It's for /k outpost.
For more information about outpost structures, see here.

Tip

Another mechanic similar to Outposts is called plunders which is an alternative to the default
champion style invasions. If this addon doesn't quite match your requirements, check that out as well.

Outposts are regions around the map that are created with WorldGuard. Once an outpost is available, players from different kingdoms will have to fight other kingdoms and keep all their members inside this region. Once the event ended, the kingdom that had the most time in the region will win and will be rewarded with resource points, money and items.

In addition to that, mobs can be configured to spawn in the area that can drop loot if provide additional bonus points when killed by
a member of a certain kingdom.

The following settings are not required, but preferred to be used.
* Players killed during this event will lose their items.
* Other than the outpost region, the surrounding regions should have PvP flag on.
* Other than the outpost region, the surrounding regions should have Build and Explosions flag off.

You can create an outpost zone by doing /k outposts create <region> and it'll save to outposts.yml config file.
Event rewards, limits, spawn location and etc can be changed there later.

Kingdoms that want to participate in this event will have to pay a small fee (from kingdom bank and resource points). There will also be a minimum and maximum members per a kingdom allowed to only enter this event. Any member can join, but they will not be allowed once it's full.
Once the event started with /k outposts start <region> <time>, kingdom members with WITHDRAW permission can participate in these events by doing /k outposts join <region> and then, members can tp to the arena, using /k outposts tp Outposts spawn should be set outside of the arena.

You can also set spawners from a custom mob plugin to make the event more challenging. You'll see a bossbar showing the event time progress when you're in the arena.

Once the event has ended, all the players that lost the event, will be teleported back to the arenas spawn. They won't be able to enter the arena. Money and resource points rewards will be added to the kingdom directly. Item rewards will spawn at another location in the arena set in the outpost config. Anyone can pickup these items.

These kind of events are usually ran with other plugins to make things more interesting. Such as setting up a spawner to spawn custom mobs or random items drops which are either managed by a plugin or a server administrator.
