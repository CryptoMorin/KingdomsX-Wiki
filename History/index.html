General History¶

Date Title Description
~2012 Prelude A guy by the name of Koolaid5000 (in-game username labbe) created a factions server called TerraminingMC (2013-2020 with the IP terramining.zapto.org:53565). Labbe made a custom cracked launcher with this server specifically in mind, which increased the popularity of the server.
~2013 Beginning The plugin was made as proprietary software by simply the name of Kingdoms by the developer Hex_27 (also known as with his newer name, Hex_26) for TerraminingMC hired by labbe which then the server switched from Factions to Kingdoms. Hex is still with us today.
Apr 25, 2015 First Release You can find the demo version of the plugin on both Bukkit and Spigot, however the Premium version called Kingdoms+ was deleted.
